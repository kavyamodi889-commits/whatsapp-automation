# BizBot AI — Intelligent WhatsApp Business Automation & CRM

> An AI-powered conversational sales & support engine with omnichannel WhatsApp integration, dynamic appointment booking with calendar slots, multi-category support ticketing, voice speech-to-text, and live webhook JSON telemetry.

---

## 🚀 Key Features

- **🤖 Conversational Intent Engine**: Context-aware intent detection for pricing inquiries, consultation scheduling, support tickets, product overviews, and special offers.
- **💬 Direct WhatsApp Cloud API & Web Handoff**: 1-click dispatch to WhatsApp with pre-formatted consultation details, support tickets, and inquiry metadata.
- **📅 Dynamic Consultation Booking**: Interactive calendar date selector, time slot chips, service category intake, and instant confirmation.
- **🎫 Support Ticketing with Attachments**: Multi-category support desk with screenshot file uploads and priority escalation levels.
- **📊 Real-time CRM Leads Dashboard**: Filterable and searchable leads manager with direct click-to-chat WhatsApp links, status management, and CSV export.
- **🎙️ Voice Speech-to-Text**: Hands-free dictation powered by the browser Web Speech API.
- **🔔 Web Audio Synthesizer**: Subtle UI audio feedback on message send and receive.
- **⚡ Live Webhook JSON Drawer**: Real-time extraction of structured payload data ready for CRM/webhook ingestion.

---

## 🛠️ Tech Stack

- **Frontend**: Pure Semantic HTML5, Modern CSS3 with Custom Properties & Glassmorphism
- **JavaScript**: Vanilla ES6+ Engine (zero dependencies)
- **APIs & Web Standards**:
  - WhatsApp Click-to-Chat / Cloud API Webhook schema
  - Web Speech API (`SpeechRecognition`)
  - Web Audio API (Oscillator/Gain synthesis)
  - HTML5 LocalStorage persistence

---

## 💻 Getting Started

Simply open `index.html` in any modern web browser or serve it with any static server:

```bash
# Using Python
python -m http.server 3000

# Or using npx serve
npx serve .
```
